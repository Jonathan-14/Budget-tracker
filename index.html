Backup & restore

Keep a portable copy of your MoneyMap data.

⟳

Automatic local backups

MoneyMap keeps up to 10 recent versions of your data in this browser whenever your saved data changes. These backups stay on this device and are not a substitute for downloading a backup file.

Checking automatic backup status…

⇩

Export a full backup

Download your transactions, budgets, recurring schedules, savings goals, and theme settings as a JSON file.

⇧

Restore from backup

Import a MoneyMap JSON backup. Restoring replaces the data currently saved in this browser.

Important: export a fresh backup first. Restoring overwrites the current MoneyMap data.

Before you restore

  • Use a JSON file exported by MoneyMap.
  • Check that it contains the data you expect.
  • Confirm the replacement when prompted; MoneyMap downloads a safety copy first.
  • Keep backup files somewhere safe; they may contain sensitive financial details.
